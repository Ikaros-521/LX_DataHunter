# CLAUDE.md - 项目开发规范

## 文档同步规范

**核心原则：代码实现与文档描述必须保持一致。任何代码变更都需要同步更新相关文档。**

### 更新规则

1. **代码变更后，判断是否影响文档描述的内容**
   - 如果修改了核心流程逻辑 → 更新对应的流程文档

2. **文档更新必须和代码变更在同一个 commit 中**
   提交内容使用中文描述，并按照以下格式：
   ```bash
   git add <代码文件> <文档文件>
   git commit -m "feat(xxx): 功能说明
   
   - 修改了 xxx
   - 更新了相关文档"
   ```

3. **保持文档简洁准确**
   - 更新相关章节即可，不需要面面俱到
   - 代码示例要与实际实现一致
   - 在文档末尾的"更新记录"中添加一条记录

## 其他规范

- 使用 type hints 和 docstring
- 遵循 PEP 8 编码规范
- 核心逻辑必须有测试
- 不要将 API 密钥硬编码或提交到 Git
